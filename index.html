توضیح پروتکل‌ها و نحوه کار How the Protocols Work

⚡ Smart Connect

حالت اتصال هوشمند برای کمک به انتخاب روش یا مسیر مناسب؛ نتیجه به سرور و وضعیت شبکه بستگی دارد. A smart connection mode to help select a suitable method or route; results depend on server and network conditions.

🛡 Psiphon

موتور اتصال Psiphon با روش‌های سازگار با شبکه‌های محدود؛ دسترسی به شرایط شبکه و سرور وابسته است. Psiphon connection engine with methods designed for restricted networks; availability depends on network and server conditions.

🧩 Aether / Shard

موتورهای اتصال و پیکربندی‌های مرتبط، برای حالت‌هایی که در برنامه و سرور پشتیبانی می‌شوند.Connection engines and related configurations for modes supported by the app and server.

🔗 WireGuard

پروتکل مدرن، سریع و سبک با مصرف باتری کم و IP نسبتاً ثابت. مناسب استفاده روزمره. Modern, fast and lightweight protocol with low battery usage and consistent IP. Great for daily use.

☁️ WARP / gool

بر پایه Cloudflare. IP را تغییر می‌دهد و حریم خصوصی بالاتر ایجاد می‌کند. نسخه gool مقاومت بیشتری دارد. Based on Cloudflare. Changes your IP and enhances privacy. gool version offers stronger filter resistance.

🚀 MASQUE

مبتنی بر HTTP/3 (QUIC). ترافیک را شبیه وب معمولی می‌کند و در محیط‌های محدود بسیار مؤثر است. Based on HTTP/3 (QUIC). Makes traffic look like normal web traffic and works well where classic tunnels are blocked.

🧅 Tor

ترافیک را از شبکه Tor عبور می‌دهد و ناشناس‌سازی بالایی ایجاد می‌کند. قابل اجرا روی WARP یا WireGuard. Routes traffic through Tor for high anonymity. Can run over WARP, WireGuard or direct.

📡 V2Ray / Xray

پشتیبانی کامل از Xray. لینک‌های VLESS، VMess، Trojan و Hysteria2. سابسکرایب و پینگ خودکار. Full Xray support. Works with VLESS, VMess, Trojan and Hysteria2. Includes subscription and auto-ping.

🛰️ CDN Fronting

قابلیت استفاده از روش CDN Fronting در حالت‌های پشتیبانی‌شده، برای عبور اتصال از مسیرهای سازگار با شبکه. عملکرد آن به تنظیمات، سرویس مقصد و وضعیت شبکه بستگی دارد. CDN Fronting is available in supported modes to route connections through compatible network paths. Availability depends on configuration, destination service and network conditions.

🎭 SNI Spoofing

قابلیت تغییر یا شبیه‌سازی مقدار SNI در حالت‌های سازگار، برای تنظیم نحوه معرفی مقصد در اتصال TLS. پشتیبانی و نتیجه به موتور اتصال و تنظیمات بستگی دارد. SNI Spoofing can alter or imitate the SNI value in compatible modes, changing how the destination is indicated during TLS setup. Support and results depend on the connection engine and configuration.

🤖 دسترسی به ابزارهای هوش مصنوعی و Google Flow 🤖 AI Tools and Google Flow Access

با انتخاب سرور و روش اتصال مناسب، می‌توانید برای دسترسی به سرویس‌های هوش مصنوعی و ابزارهایی مانند Google Flow در شبکه‌های دارای محدودیت تلاش کنید. دسترسی نهایی به شرایط شبکه، سرور، منطقه و قوانین سرویس مقصد وابسته است. Choose a suitable server and connection method to try accessing AI services and tools such as Google Flow on restricted networks. Availability still depends on network conditions, server location, and the destination service’s eligibility rules.

قابلیت‌ها و امکانات برنامه Features and App Capabilities

🌐 تلاش برای اتصال در شرایط اینترنت ملیConnection Attempts During National-Network Restrictions

چندین پروتکل و روش اتصال در اختیار کاربر قرار می‌گیرد تا در زمان محدودیت شدید یا شرایط موسوم به اینترنت ملی، روش‌های سازگار را امتحان کند. موفقیت اتصال به اپراتور، نوع محدودیت، سرور و وضعیت لحظه‌ای شبکه وابسته است و تضمین نمی‌شود.Multiple protocols and connection methods let users try compatible routes during severe restrictions or national-network conditions. Success depends on the carrier, restriction type, server and current network state, and is not guaranteed.

🎮 استفاده عمومی و گیمینگEveryday Use and Gaming

مناسب برای وب‌گردی، برنامه‌های روزمره و امتحان‌کردن سرورهای مناسب بازی؛ با انتخاب سرور بر اساس Best Ping و پایش پینگ. پینگ پایین یا کاهش تأخیر تضمین نمی‌شود و به فاصله سرور، مسیر اینترنت و شلوغی شبکه بستگی دارد.For browsing, everyday apps and trying game-friendly servers, with Best Ping server selection and ping monitoring. Low ping or reduced latency is not guaranteed; it depends on server distance, routing and network congestion.

🌍 مدیریت سرورهاServer Management

Smart Connect، انتخاب بر اساس Best Ping، انتخاب دستی، سرورهای دارای IP ثابت در صورت موجود بودن، اشتراک سرور، افزودن کانفیگ دلخواه، علاقه‌مندی‌ها و تاریخچه اتصال.Smart Connect, Best Ping, manual selection, static-IP servers when available, subscriptions, custom configs, favorites and connection history.

🧭 ابزارهای سرور و مسیرServer and Route Tools

انتخاب منطقه خروجی Psiphon همراه پرچم و اطلاعات سرور، IP Scanner، نمایش IP خروجی، پایش پینگ و وضعیت اتصال بالادستی، Obfuscation و Custom Endpoint.Psiphon exit-region selection with flags and server details, IP Scanner, exit IP, ping and upstream status, obfuscation and custom endpoints.

🔌 پروکسی محلی و اشتراک‌گذاریLocal Proxy and Sharing

Device VPN، پروکسی محلی، SOCKS5، HTTP Proxy، تنظیم آدرس و پورت، اشتراک‌گذاری در LAN و HTTP CONNECT؛ اشتراک‌گذاری WARP، WireGuard و V2Ray در حالت‌های سازگار.Device VPN, local proxy, SOCKS5, HTTP proxy, custom address and port, LAN sharing and HTTP CONNECT; WARP, WireGuard and V2Ray sharing in supported modes.

🛡️ امنیت و پایداریSecurity and Stability

Kill Switch، تلاش برای اتصال مجدد خودکار، Private DNS، سازگاری با Always-on VPN اندروید و Fail-Closed در شرایط تعریف‌شده و پشتیبانی‌شده.Kill Switch, automatic reconnection attempts, Private DNS, Android Always-on VPN compatibility and Fail-Closed in defined supported conditions.

🧩 Split Tunneling

انتخاب برنامه‌هایی که از تونل عبور کنند یا خارج از آن بمانند؛ جست‌وجوی برنامه‌ها، انتخاب همه و پاک‌کردن انتخاب‌ها.Choose which apps use the tunnel or bypass it, with app search, select-all and clear-selection controls.

📊 نمایش و پایش ترافیکTraffic Monitoring

نمودار ترافیک، Sparklines، نمایش گرافیکی وضعیت اتصال، نشانگرهای وضعیت و اعلان‌های اتصال.Traffic charts, sparklines, graphical connection status, status indicators and connection notifications.

🧰 گزارش‌ها و عیب‌یابیLogs and Troubleshooting

گزارش‌های متنی سبک ترمینال برای V2Ray و Psiphon، مشاهده و کپی گزارش‌ها، تنظیم سطح لاگ، تنظیم MTU، بازگردانی تنظیمات و راهنمای اتصال.Terminal-style V2Ray and Psiphon logs, view/copy logs, logging level, MTU settings, reset defaults and connection guides.

🎨 رابط کاربریUser Interface

زبان فارسی و انگلیسی، تم تیره، مقایسه اطلاعات پروتکل‌ها، اطلاعات نسخه و Quick Settings Tile برای دسترسی سریع از پنل تنظیمات اندروید.Persian and English, dark theme, protocol comparison, version information and a Quick Settings Tile for faster access from Android settings.

📺 Android TV / Leanback

پشتیبانی از رابط مناسب تلویزیون‌های اندرویدی در نسخه‌ها و دستگاه‌های سازگار.TV-friendly interface support on compatible Android TV devices and versions.

بررسی نسخه جدید، دانلود به‌روزرسانی در حالت‌های پشتیبانی‌شده، تأیید نصب، توضیحات انتشار و به‌روزرسانی اجباری در شرایط تعریف‌شده.Check for updates, download in supported modes, installation confirmation, release notes and forced updates under defined conditions.
